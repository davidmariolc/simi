Simi

Política de privacidad

Última actualización: 12 de noviembre de 2026

Simi traduce el texto que seleccionas del inglés al español mediante los modelos locales de Chrome. La extensión no envía tus selecciones a un servidor de traducción, no guarda un historial de traducciones y no incorpora publicidad ni herramientas de analítica.

1. Responsable y alcance

Simi es una extensión de Chrome mantenida por DavidMarioLC. Esta política describe cómo la extensión maneja información al traducir selecciones en páginas web, notebooks de GitHub y su visor de documentos PDF.

2. Información que procesa Simi

  • Texto seleccionado y traducciones. Simi lee la selección para traducirla y mostrar el resultado junto al texto. Utiliza temporalmente el texto y su posición en la página para colocar la burbuja. El texto puede contener información personal si tú la seleccionas. Simi no lo añade a un historial ni lo guarda en almacenamiento persistente.
  • Notebooks de GitHub. La selección y su posición se comunican entre el visor incrustado y la página de GitHub mediante mensajes internos de la extensión. Este intercambio no envía la selección a un servidor de Simi.
  • Preferencia de activación. Simi guarda localmente, mediante el almacenamiento de la extensión en Chrome, si la traducción automática está activada o desactivada. No sincroniza esta preferencia mediante su propio servicio.
  • Documentos PDF. El visor lee el archivo local que eliges o descarga el PDF de la dirección que abres. Procesa el contenido, el nombre del archivo y las búsquedas dentro del documento durante su uso. No sube los archivos locales a un servidor ni crea una biblioteca persistente de documentos.
  • Progreso de lectura de PDF. Simi guarda en el perfil de Chrome solo una huella calculada a partir del contenido del PDF y el último número de página. Usa ese dato para retomar la lectura al abrir el mismo documento en ese perfil.
  • Dirección de la pestaña. Al pulsar «Abrir en Simi», la extensión consulta la URL de la pestaña activa para abrir el documento en su visor. La dirección se transmite internamente mediante una sesión temporal; no se guarda como historial de navegación.

3. Procesamiento local y conexiones de red

La traducción se realiza en el dispositivo mediante la API Translator de Chrome. Chrome puede necesitar conexión para descargar o preparar sus modelos de traducción. Estas descargas y el funcionamiento del navegador están gestionados por Chrome y sujetos a las políticas de Google.

Al abrir un PDF de internet, Simi realiza una solicitud al sitio que aloja el documento, que recibe la información habitual de una conexión, como la dirección IP y la URL solicitada. La solicitud puede incluir las cookies o credenciales de sesión que Chrome permita para ese sitio. Esto permite acceder a documentos que requieren una sesión iniciada. El documento se procesa en el visor de Simi; no se reenvía a un servicio de traducción.

Simi no tiene un servidor propio para recibir selecciones, traducciones o documentos. No incorpora telemetría, seguimiento publicitario ni un sistema de cuentas. No vende ni comparte estos datos para publicidad, evaluación crediticia u otros fines ajenos a la traducción solicitada.

4. Permisos

  • Almacenamiento: conserva la preferencia de activación y la última página de lectura de cada PDF en el navegador.
  • Pestaña activa: permite consultar la dirección de la pestaña cuando utilizas la acción para abrir un PDF en Simi.
  • Acceso a sitios HTTP y HTTPS: permite leer las selecciones y mostrar su traducción en los sitios autorizados. El visor solicita permiso para el sitio de origen cuando lo necesita para descargar un PDF. Puedes gestionar el acceso a sitios desde la configuración de extensiones de Chrome.

5. Conservación y control

Las selecciones, traducciones y documentos se utilizan temporalmente durante la sesión. Simi no los escribe en un historial persistente. Puedes cerrar la burbuja o la pestaña del visor y desactivar la traducción automática desde el menú de la extensión.

La preferencia de activación y el progreso de lectura permanecen en el almacenamiento local de la extensión. Puedes eliminar ambos datos borrando los datos de la extensión o desinstalando Simi. Los permisos concedidos se administran en Chrome.

Los modelos descargados, las cachés y otros datos administrados por Chrome o el sistema operativo se gestionan con sus propios controles. Simi no garantiza el borrado inmediato de todas las copias temporales que estos sistemas puedan mantener.

6. Servicios externos y esta página

Las páginas que visitas, GitHub, los sitios que alojan PDFs y Chrome tienen sus propias prácticas de privacidad. Esta página se publica con GitHub Pages; GitHub puede procesar información técnica de las visitas conforme a su declaración de privacidad. Esta página no carga fuentes, scripts de analítica ni recursos de terceros.

El uso de información por Simi se limita a ofrecer las funciones descritas y cumple la Política de Datos del Usuario de Chrome Web Store, incluidos los requisitos de uso limitado.

7. Cambios y contacto

Actualizaremos esta política cuando cambie el manejo de información de Simi e indicaremos la fecha de actualización en esta página.

Para consultas sobre privacidad, puedes abrir una solicitud en GitHub Issues de Simi. Las solicitudes son públicas: evita incluir selecciones, documentos o información personal sensible. Solo recibimos la información que decides publicar allí, y GitHub la gestiona conforme a sus propias políticas.
